# hist-dutch-travelogues-nlp

An integrated NLP pipeline for NER, Zero-Shot Entity Linking, and ground-truth-to-PageXML mapping of 19th-century Dutch travelogues. Part of the Academic Tourism project at the University of Groningen. The primary source is letters from a Groningen student traveling through Germany (~1816) for his *Bildung*.

## Modules

### NER (`ner/`)

Named Entity Recognition via spaCy + `spacy-llm` with Ollama as the LLM backend. Extracts `E53_Place` (geopolitical entities) and `E19_Physical_Thing` (buildings, landmarks) from source text split into numbered pages. Configured via `ner/ner_config.cfg` with few-shot examples and a Dutch-domain Jinja2 prompt template.

| Script | Purpose |
|--------|---------|
| `ner/ner.py` | Run NER pipeline, output `.spacy` DocBin and offset map |
| `ner/ner_evaluate.py` | Evaluate predictions against Recogito manual annotations (strict + relaxed F1) |
| `ner/ner_displacy.py` | Visualize `.spacy` results in browser with Wikidata links (if entity linking is done first) |

### Entity Linking (`entity_linking/`)

Three-stage LELA-inspired architecture that links NER entities to Wikidata and GeoNames knowledge bases.

| Stage | Script | Description |
|-------|--------|-------------|
| 1 | `el_candidates.py` | EPG (Entity Profile Generation): LLM predicts modern name/region/type from archaic context, then queries Wikidata (text + SPARQL), Wikipedia full-text, and GeoNames |
| 2 | `el_reranker.py` | LLM pointwise scoring of candidates, with heuristic fallback (Levenshtein + domain-term overlap weighted toward German/Dutch geography) |
| 3 | `el_selector.py` | LLM selects best candidate from top-k, with Wikipedia extract enrichment |
| — | `el.py` | Orchestrator that runs all three stages and writes `_el.spacy` files with `kb_id_` set on entities |

### GT-to-PageXML Mapping (`ground_truth_mapping/`)

Corrects HTR (Handwritten Text Recognition) output in PageXML files by aligning each noisy line to ground truth transcriptions via Ollama.

| Script | Description |
|--------|-------------|
| `gt_to_pagexml_local.py` | Local execution with `gemma4:31b-cloud` |
| `gt_to_pagexml_hpc.py` | HPC (Habrok) execution with `gemma4:31b` and 1200s Ollama timeout |

## CSV Files

### Static data

**`data/1816-scannumber-to-pagenumber.csv`** — maps digitization scan numbers to manuscript page numbers.

| Column | Type | Description |
|--------|------|-------------|
| `Scan Number` | int | Scan identifier from the digitization process |
| `Page Number` | str | Roman or Arabic numeral page number in the manuscript |

### NER evaluation output

**`ner/ner-results/*_errors.csv`** — instance-level NER errors, generated by `ner/ner_evaluate.py` using relaxed (overlap-based) matching.

| Column | Type | Description |
|--------|------|-------------|
| `type` | str | `TP` (true positive), `FP` (false positive), or `FN` (false negative) |
| `label` | str | Entity label: `E53_Place` or `E19_Physical_Thing` |
| `page` | int | Page number where the entity appears |
| `gold_text` | str | Ground truth entity text (empty for FP) |
| `pred_text` | str | Predicted entity text (empty for FN) |
| `gold_start` | int | Gold span start character offset, page-local (empty for FP) |
| `gold_end` | int | Gold span end character offset, page-local (empty for FP) |
| `pred_start` | int | Predicted span start character offset, page-local (empty for FN) |
| `pred_end` | int | Predicted span end character offset, page-local (empty for FN) |

### GT mapping output

Produced at runtime by `gt_to_pagexml_*.py` in `data/page_updated/`.

**`report_summary.csv`** — per-page mapping statistics.

| Column | Type | Description |
|--------|------|-------------|
| `filename` | str | PageXML filename |
| `total_lines` | int | Number of HTR text lines on the page |
| `corrected_lines` | int | Lines successfully mapped to ground truth |
| `unmatched_lines` | int | Lines with no GT equivalent |
| `confidence` | float | LLM-reported alignment confidence (0.0–1.0) |
| `fuzzy_accuracy` | float | SequenceMatcher similarity: recovered vs. original GT (0–100%) |
| `gt_chars_total` | int | Total characters in the ground truth page |
| `gt_chars_mapped` | int | Characters covered by the mapping |
| `gt_coverage_pct` | float | Percentage of GT characters covered |
| `status` | str | `mapping_attempted`, `no_mapping`, or `no_gt` |

**`report_unmatched.csv`** — detail of HTR lines that could not be mapped.

| Column | Type | Description |
|--------|------|-------------|
| `filename` | str | PageXML filename |
| `line_index` | int | Index of the unmatched HTR line |
| `original_text` | str | The unmatched HTR text content |

## Data

| Path | Description |
|------|-------------|
| `data/1816_third_letter.txt` | Source travelogue text, split into pages with `[N]` markers |
| `data/GT_1816_for_mapping.txt` | Ground truth transcription for PageXML correction |
| `data/page/` | PageXML files with HTR output (`.xml` + `.png` pairs) |
| `ner/gs-annotations.jsonld` | Recogito manual NER annotations for evaluation |
| `ner/ner-results/` | NER/EL output `.spacy` files and `*_errors.csv` files (gitignored) |

## Running

```bash
# NER pipeline (requires Ollama at localhost:11434)
python ner/ner.py

# Evaluate NER against manual annotations
python ner/ner_evaluate.py

# Visualize NER/EL results in browser
python ner/ner_displacy.py

# Entity Linking (edit SPACY_FILE in el.py first)
python entity_linking/el.py

# GT-to-PageXML mapping (local)
python ground_truth_mapping/gt_to_pagexml_local.py

# GT-to-PageXML mapping (HPC)
sbatch SLURM/gt_to_pagexml_mapping.sh
```
